# QR Code Generator

A simple and responsive QR Code Generator built using **HTML, CSS, and JavaScript**. This web app allows users to generate QR codes instantly for any text or URL input.

It uses a lightweight JavaScript QR code library and provides a clean, user-friendly interface for quickly generating scannable QR codes.

## 🚀 Live Demo

👉 [View Live Project](https://qr-code-generator-hazel-six.vercel.app/)

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* QR Code API

## ✨ Features

* Generate QR codes instantly
* Supports text and URLs
* Simple and responsive interface
* Easy to use
* Fast QR code generation
